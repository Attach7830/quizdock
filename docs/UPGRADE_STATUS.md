# Upgrade status

The classroom beta’s actual source is integrated in release 0.3.1. See `RELEASE_2026_11_14.md` for features and exact validation scope. The old single-file installer is obsolete and should not be part of the Cloudflare deploy command.

Implemented: accounts/classes, typed assignments/accent entry, solo flashcards, raffles, skins/rewards, six modes, game settings, saved lists/images/reports, mobile reflow and same-PIN rounds. Added: data export/restore, student erasure, opt-in retention, release diagnostics and health checks.

Remaining operational checks: actual deployment, school email delivery, physical phone layout, real-class network/load and school approval. Teacher workspace closure and provider-level full-disaster recovery are administrator-managed. Gradebook integration is not included; teacher CSV exports are provided.
