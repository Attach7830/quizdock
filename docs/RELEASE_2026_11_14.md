# Classroom integration release · 2026-11-14

Base: main `9d9f7caf3252ff77b9dfc3a00d2caeedf95f6bc0`. Release identifier: `classroom-release-2026-11-14.1`.

## Integration

The prepared classroom beta is committed as ordinary editable source, not expanded during the Cloudflare build. The newer mobile fix’s natural page scrolling, wrapped controls and reachable answers are incorporated in `public/platform.css`. Older renderer files remain for historical regression tests but are no longer loaded by the new home/play pages.

Existing teacher lists, reports, login recovery markers, SQLite classes and secrets are retained. No data deletion or retention policy is enabled merely by upgrading. Do not deploy in the middle of a graded class session; reload existing tabs once after deployment to load the new renderer.

## Included

- Verified student email accounts, teacher-controlled classes, rosters and invitation codes.
- Class-specific live games and assignments due this week, overdue work, and submitted practice.
- Typed independent practice with time, card-count and accuracy thresholds. Card count can mean answer attempts or distinct cards. Accent strictness, contextual accent entry, server grading and resumable progress.
- Ungraded solo flashcards; cosmetic skins bought with server-earned points.
- Six animated game modes including Sky Rally/Crystal Keep role tradeoffs. Per-round late-entry policy, time/score endings and same-PIN replay with optional new saved list.
- Weekly first-place or 3/2/1 weighted raffles; idempotent reward payouts and separate card reports.
- Data & privacy: signed backup/restore with preview, class-scoped student erasure, student self-deletion, opted-in retention, public/private diagnostics and read-only health checks.

## Local validation performed

The release’s Node suite includes 131 passing tests: the prepared beta, new data-management tests, the prior teacher lockout and same-room replay tests, a 45-player simulated classroom test, and read-only health-probe tests. Historical animation unit tests remain unchanged in GitHub and are additionally exercised by repository CI.

The 45-player test sends concurrent answer bursts, duplicate retries and reconnects through the real QuizRoom logic with the in-memory storage adapter. All six rounds archive 135 attempts each with the expected correctness totals. A separate fake email test verifies that 45 students sharing one IP can request and verify codes. This is not a Cloudflare performance or deliverability benchmark.

The browser suites exercise real UI modules against a fake-account local adapter. The classroom suite has 59 assertions; release/data-management checks have 34. They cover short viewports, image/long prompts, accents, same-room transitions, backup signatures, retention previews and session revocation. Keyboard testing uses a shortened viewport, not a physical phone keyboard.

JavaScript syntax checks pass. Runtime secrets, real student emails and production storage are not used in tests. CI separately checks the combined repository and a Wrangler dry-run bundle. See CI results for those outcomes; do not infer them from local tests.
