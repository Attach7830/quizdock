# Practice, navigation and Servite enrollment

Release marker: `classroom-release-2026-11-15.2` (0.7.1).

Typed answers interpret semicolons as alternative meanings. For a saved answer `tight; narrow`, `tight`, `narrow`, and the complete original answer are accepted. Explicit accepted alternatives and correct choice-card answers follow the same rule. Case, whitespace, Unicode normalization, required accents and the distinction between n and ñ keep their existing behavior. Commas, slashes and the word “and” remain literal. Saved lists and historical grades are not rewritten. Round analytics use the same matcher as typed grading.

Each study/game format presents shuffled passes: solo flip cards, solo typed practice, graded assignments, the six original multiple-choice games, Word Forge and shared Sketch Relay words. A pass visits each eligible card once before drawing a new pass; with multiple cards, a new pass avoids repeating the last card immediately. Drawing keeps its rotating artist order independently of word order. Server-owned card order persists through reconnects, and original card IDs still own grades and report counts. Existing in-progress sequential assignments retain their active prompt or feedback, then enter shuffled order on advancement. Existing active game questions are also retained until advancement.

Assignments has a separate top navigation destination at `/?view=assignments`. It contains graded work, due dates, submissions and teacher assignment creation. Arcade contains class games, solo study, classes, character purchases and the raffle. Returning from graded work returns to Assignments. Unsent drafts remain in the browser tab, and checked answers retain their existing server persistence.

The Keys button in the home, game, list, report and data navigation opens an accessible, scrollable keyboard guide. `?` also opens it. Press G then H for Arcade, G then A for Assignments, G then L for My lists, G then R for reports, or G then D for data controls where the destination is available. Enter submits a typed answer through its normal form and, after feedback, loads the next graded or solo typed card. Space flips an ungraded flashcard. Existing accent and Tab controls remain. Custom shortcuts pause in editable controls and dialogs, ignore composition/modifier keys and held-key repeats, and can be disabled on the device. Navigation activates existing links, retaining the editor's unsaved-draft guard. Assignment submission and live answer selection retain their explicit controls.

New students with an exact verified `servitehs.org` Google Workspace identity can create their account before enrollment. Both the verified email domain and Google's signed Workspace domain must match. They next see a class-code form (including when arriving from a game PIN link, which resumes after enrollment); no class records become visible before enrollment succeeds. Joining fills the roster with the verified Google display name and email, without a typed name or teacher roster entry. Invalid/closed/rotated codes, removed memberships, disabled accounts and mismatched Google subjects keep their existing guards. Teachers retain their allowlist and separate login. Existing students and invitation links keep their established access flow and account IDs, grades, balances and teacher-assigned roster names.

Validation uses fake local accounts and an isolated Google test issuer. Server checks cover both meanings, typed report totals, complete shuffled passes in all eight live modes, reconnects, legacy practice migration and verified school enrollment. Browser checks cover the separate navigation, actual Enter progression, held Enter, text/IME guards, disabled shortcuts, unsent drafts, mobile guide scrolling, automatic school roster names and native unsaved-editor navigation protection. Commit, merge, deployment and public verification are recorded separately in the release PR. Real school account consent, physical devices and inbox delivery are separate manual checks.

Local validation passed: 274 Node tests, source syntax/whitespace checks, 462 browser assertions across all eight suites, and the Wrangler deployment dry-run. Tests use isolated fake accounts and a signed Google test issuer. Production status is recorded separately in the PR after merge and public checks.
